# نرخ ارز 💱

اپ قیمت لحظه‌ای **ارز، طلا و سکه و رمزارز** بازار ایران با دیزاین iOS — نسخه وب + اپ دسکتاپ ویندوز با آپدیت خودکار.

## ✨ امکانات

- **۹۱ دارایی**: ۳۹ ارز جهانی، ۱۲ طلا و سکه، ۴۰ رمزارز
- **پروفایل واقعی برای همه**: پرچم SVG لوکال برای ارزها (حتی دلار کانادا 🇨🇦!) و آیکون اختصاصی رمزارزها
- **تبدیل ارز**: تبدیل هر دارایی به دیگری — با این همه دلار چقدر یورو می‌گیرید؟ (نرخ مستقیم و معکوس)
- **دوزبانه**: فارسی (RTL / تومان) و انگلیسی (LTR / دلار)
- **دیزاین iOS**: تم روشن/تیره، هدر بلور، bottom sheet، انیمیشن‌های نرم
- **نمودار قیمت**: ۷ / ۳۰ / ۹۰ روز و ۱ سال
- **علاقه‌مندی‌ها** و جستجوی سریع
- **ویجت شناور** قیمت‌ها (Document PiP)
- **آپدیت خودکار**: نسخه‌های جدید بدون دانلود مجدد، از داخل خود برنامه نصب می‌شن

## 📥 نصب (ویندوز)

از صفحه [**Releases**](../../releases) آخرین نسخه `CurrencyRates-Setup-x.x.x.exe` رو دانلود کنید:

1. فایل رو اجرا کنید و مسیر نصب رو انتخاب کنید
2. شورتکات دسکتاپ و استارت‌منو خودکار ساخته می‌شه
3. تمام! نسخه‌های بعدی خودکار از داخل برنامه آپدیت می‌شن

> 💡 چون برنامه هنوز کد-ساین نشده، اولین بار ویندوز SmartScreen هشدار می‌ده: **More info → Run anyway**

## 🖼 پیش‌نمایش

- لیست قیمت‌ها با پرچم و آیکون اختصاصی هر دارایی
- تب تبدیل: دلار → یورو / یورو → هریونیا / هر ترکیب دلخواه
- نمودار قیمت هر دارایی در بازه‌های زمانی مختلف

## 🚀 اجرا برای توسعه‌دهنده‌ها

```bash
bun install

# وب (dev)
bun run dev          # http://localhost:3000

# بیلد وب (production)
bun run build

# ساخت نصاب ویندوز (NSIS)
bun run electron:build   # خروجی: dist-out3/CurrencyRates-Setup-*.exe
```

## 🛠 تکنولوژی‌ها

Next.js 16 (App Router) · React 19 · TypeScript 5 · Tailwind CSS 4 · shadcn/ui · TanStack Query · Zustand · recharts · framer-motion · Electron 45 + electron-updater

## 📡 منابع داده

نرخ‌ها از وب‌سایت‌های داخلیِ نرخ بازار آزاد ایران دریافت و با APIهای جهانی به‌عنوان پشتیبان ترکیب می‌شن. پرچم‌ها (پروژه [flag-icons](https://github.com/lipis/flag-icons)) و آیکون‌ها به‌صورت لوکال باندل شدن — اپ دسکتاپ حتی آفلاین آیکون‌ها رو داره.

## 📁 ساختار پروژه

```
├── electron/            # main + preload (اپ دسکتاپ)
├── scripts/             # اسکریپت‌های بیلد دسکتاپ
├── src/
│   ├── app/api/         # API نرخ‌ها و نمودار تاریخی
│   ├── components/currency/  # UI (لیست، تبدیل، نمودار، بنر آپدیت...)
│   └── lib/             # رجیستری ۹۱ دارایی، پارسر نرخ‌ها، i18n، استور
├── public/flags/        # ۳۹ پرچم SVG لوکال
├── public/crypto/       # ۴۰ آیکون رمزارز لوکال
├── electron-builder.yml # تنظیمات نصاب NSIS
└── BUILD-EXE.md         # راهنمای ساخت EXE
```
